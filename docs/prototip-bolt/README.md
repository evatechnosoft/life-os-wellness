# Bolt prototipi — 3 sayfa × 2 varyasyon (2026-11-11)

ZimaOS'taki bolt.diy ile üretildi (OpenAILike → claude). Girdi: `../img/varyasyon-2026-11-11.png` + `../img/bolt-prompt-2026-11-11.md`.
Bağımsız Vite + React + Tailwind 3 projesi; uygulamanın koduna bağlı değil, veri sahte.

| Sayfa | A | B |
|---|---|---|
| 1 · Özet (Gün/Hafta/Ay) | halka | çubuk |
| 2 · Takip | gün zaman çizelgesi | sıradaki seans + hızlı kayıt |
| 3 · Diğer | gruplu kutu ızgarası | katlanır liste |

Çalıştır: `npm install && npm run dev` → `?v=1A` … `?v=3B`, hepsi için `?v=all`.
Ekran görüntüleri: `ekran/`.
